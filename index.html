Install and Boot a System

01

Download

Choose a system above and download its ISO from the official publisher. Avoid third-party repacks; check the publisher's checksum when one is provided.

02

Create a Virtual Machine

In VirtualBox or VMware, create a VM for the operating system you downloaded. Assign suitable memory, CPU cores, and a new virtual disk.

03

Attach and Boot the ISO

Open the VM's storage or CD/DVD settings, select the ISO as its optical disc, and start the VM. If needed, choose the optical drive in the VM's boot menu.

04

Install or Start Live

Follow the installer's prompts to install onto the VM's virtual disk. For live systems such as Tails or Hiren's BootCD PE, choose the live session instead. After installing, eject the ISO and restart to boot from the virtual disk.
